Tick 行情 · 使用支持

支持哪些市场？

美股、港股、A股、日股、韩股、加密货币（币安现货）、贵金属（伦敦现货、COMEX/NYMEX、上金所、沪金沪银）、主要指数与 ETF。

数据来源是什么？实时还是延时？

Tick 按市场自动路由到可用数据源（东方财富、腾讯、新浪、Yahoo、Naver、币安等）。A 股与加密货币为实时行情；港股、美股默认延时，日股延时约 20 分钟，韩股实时。行情详情页会标注数据来源与实时/延时状态。

如何获得港股/美股/A 股的官方实时行情？

设置 → 数据源 → Longbridge，用你自己的长桥账户完成浏览器授权（或填入 API Key）即可升级为官方实时行情（长桥账户需开通相应行情权限）。凭据只保存在你 Mac 的钥匙串中。

我的自选和持仓数据存在哪里？

全部保存在本机应用容器中，不上传任何服务器。删除应用即删除全部数据。

MCP 是什么？会不会有安全风险？

MCP 是让 Claude、ChatGPT 等 AI 客户端直接读写自选/持仓的本地接口，默认关闭。开启后只监听 127.0.0.1，且需要设置页显示的访问令牌，不会暴露到网络。
